## 🧩 About

**Fortnite helpers** is a curated list of Fortnite open-source tools:

- **Overlays** — on-screen helpers, layout notes, map overlay, loot tracker
- **Quality-of-Life Helpers** — HUD notes, config presets, overlay notes
- **Research Notes** — practice layouts and config notes for educational use

Based on publicly available community tools and overlay helpers.

---

## ✨ Features

### 🎮 Gameplay Helpers
- Map overlay — visualize nearby points of interest
- Loot Tracker — review nearby item spawns
- Replay Notes — record and review match runs
- HUD Scaling — adjust on-screen layout for study

### 🎨 Catalog & Cosmetics
- Skin Catalog — browse outfits, wraps, back blings
- Loadout Notes — organize player presets
- Vehicle Notes — review vehicle handling notes

### 🏋️ Practice Layout
- Practice Notes — segment study on any map
- Build Layout Notes — study building placements
- Aim Practice Notes — review aim routines in the editor

## ⚙️ Configuration

| Parameter | Type | Default | Description |
|-----------|------|---------|-------------|
| `menu_hotkey` | String | `"Tab"` | Toggle overlay |
